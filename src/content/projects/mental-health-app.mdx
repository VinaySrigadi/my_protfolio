## Overview

The Mental Health AI App is a full-stack mobile application engineered to provide accessible, private, and empathetic mental health support. Designed as a capstone project, it successfully demonstrates the end-to-end deployment of a Large Language Model (Mistral-7B) on commodity hardware.

## Architecture

The system utilizes a modern, decoupled client-server architecture:

- **Frontend (Flutter)**: A highly responsive, cross-platform mobile interface written in Dart. It features real-time conversational UI, daily mood tracking dashboards, and seamless appointment scheduling flows.
- **Backend (Flask + Python)**: A robust REST API responsible for state management, authentication, and orchestrating requests to the LLM engine.
- **Database (MongoDB Atlas)**: Cloud-native NoSQL database used to securely store user profiles, historical conversation logs, and longitudinal mood data.

## Generative AI Integration

The core feature of the application is an empathetic chatbot powered by **Mistral-7B**.

- **Prompt Engineering**: The LLM was carefully guided using system prompts to maintain a supportive, non-diagnostic, and empathetic tone suitable for mental health conversations.
- **Deployment**: The model was hosted locally/on commodity hardware, showcasing efficient inference strategies and latency optimization without relying on expensive, proprietary cloud APIs (like OpenAI), ensuring maximum user privacy.

## Features

1. **Conversational AI Therapy**: 24/7 access to a supportive AI listener.
2. **Mood Tracking**: Visual dashboards allowing users to track their emotional state over time.
3. **Appointment Scheduling**: Integrated booking system for connecting with human professionals.

## Conclusion

This capstone project proved that highly capable, open-source generative models can be successfully integrated into production-like full-stack mobile applications to deliver immediate, impactful, and privacy-preserving user experiences.
